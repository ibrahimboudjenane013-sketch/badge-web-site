# EcoGeeks • Official Member Badge & Pass Generator 🌿⚡

Système officiel de génération de badges et passes membres pour le club **EcoGeeks** (Innovation écologique & technologique).

---

## ✨ Caractéristiques & Thème EcoGeeks

- **Identité Visuelle Éco-Tech Solarpunk / Cyber-Green :**
  - Palette moderne vert émeraude (`#10b981`), menthe cyber (`#34d399`), et fond ardoise sombre texturé de circuits électroniques.
  - Logo personnalisé combinant feuille organique et pistes de circuit imprimé.
- **Badge Membre Tactile Haute Fidélité :**
  - Découpe pour tour de cou / cordon (lanyard slot).
  - Puce de contact sans contact (RFID/NFC).
  - Photo membre avec anneau holographique et badge de vérification.
  - Couleurs et icônes personnalisées par pôle :
    - 💻 **IT** : Informatique & Développement
    - 🌐 **RE** : Relations Extérieures & Partenariats
    - 👥 **RH** : Ressources Humaines & Talents
    - ⚡ **ORGANISATION** : Événements & Logistique
    - 📢 **COMMUNICATION** : Médias & Design
  - QR Code dynamique de sécurité pour authentifier le pass.
- **Expérience Utilisateur Interactive :**
  - Prévisualisation du badge en temps réel au fur et à mesure de la saisie.
  - Zone de glisser-déposer (*Drag & Drop*) intuitive pour l'import de la photo.
  - Boutons d'accès rapide pour sélectionner son département.
- **Export & Impression :**
  - 🖨️ **Impression optimisée (`@media print`)** : format carte d'accès prêt à découper et insérer dans un porte-badge transparent.
  - 📥 **Téléchargement PNG haute résolution (2x DPR)** : génération instantanée via Canvas pour sauvegarder le badge sur smartphone.
- **Persistance des Données :**
  - Traitement d'image via **Sharp** (recadrage centré, optimisation JPG).
  - Enregistrement synchronisé dans le tableur Excel `badges_database.xlsx`.

---

## 🚀 Démarrage Rapide

### 1. Installation des dépendances
```bash
npm install
```

### 2. Lancement du serveur
```bash
npm start
```

Rendez-vous sur [http://localhost:5000](http://localhost:5000) dans votre navigateur.
